# Results

This directory stores all outputs generated by training and evaluation runs.

## Contents

| File/Pattern | Description |
|---|---|
| `training_history.png` | Accuracy & loss curves across epochs |
| `prediction_01.png` … `prediction_N.png` | Side-by-side: Input \| True Mask \| Predicted Mask |

## Regenerating results

After training completes, predictions are saved automatically.  
You can also regenerate them independently:

```bash
python src/evaluate.py --num-samples 10
```

## Sample output layout

Each prediction image contains three panels:

```
┌──────────────┬──────────────┬──────────────┐
│  Input Image │  True Mask   │ Predicted    │
│  (RGB photo) │  (ground     │ Mask (U-Net  │
│              │   truth)     │  output)     │
└──────────────┴──────────────┴──────────────┘
```

Mask colour coding (Oxford IIIT Pet dataset):

| Class index | Meaning |
|---|---|
| 0 | Pet (foreground) |
| 1 | Background |
| 2 | Border / ambiguous region |
